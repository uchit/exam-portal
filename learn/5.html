Agentic ArchitectureTools & MCPClaude CodePrompt EngineeringContext & Reliability

1. Context Windows and Token Budgeting

The context window is a shared, finite budget for input and output tokens, not just the visible chat text.

7 min

2. Prompt Caching Mechanics

Prompt caching reuses a stable prefix server-side, but only the content before the first change stays cacheable.

7 min

3. Compaction and the Summarization Trap

Compaction frees context space by condensing history, but over-compacting drops details the model still needs.

8 min

4. Idempotency and Error Propagation

Idempotent tool calls survive retries safely; error handling should match response severity to failure criticality.

8 min

5. Escalation on Ambiguity

Escalate to a human only when a decision is high-stakes, hard to reverse, and confidence is genuinely low.

7 min

6. Evals and Information Provenance

Evals catch regressions systematically, and provenance tracking prevents misplaced trust in conflicting context.

7 min
